# QRQT figure code

Code and Source Data for **Quantum-Resistant Quantum Teleportation**
(Jin, Chandra, Azari, Cheng, Shen, Seshadreesan & Liu).

Everything here regenerates a figure in the paper or the numerical values behind one.
`FIGURE_INDEX.md` says, for every graphic in the paper, which script produces it and how
that was checked. Read it first: two figures come from the collaborator and their plotting
code is not here, one is vector artwork that needs Adobe Illustrator for its final step,
and one is a reimplementation rather than the original script.

## Install

```bash
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

The pinned versions are the ones the figures were verified against.

Fonts matter, and the two figure families do not use the same one. Each script now pins a
single family rather than a preference list, because the published PDFs were rendered on a
machine that had both:

* `figures/supplementary/` pins **DejaVu Serif** (ships with matplotlib). With it,
  Supplementary Fig. 1 regenerates with zero differing pixels at 300 dpi.
* `figures/fig3/` pins **Times New Roman**, which is what the published Fig. 3 PDFs used.
  On a machine without it matplotlib falls back to DejaVu Serif with a warning and the
  output will not match.

## Regenerate the figures

Each command is independent; run them from the repository root.

```bash
python figures/fig3/pqc_plot_fig3a.py
python figures/fig3/pqc_plot_fig3b.py
python figures/fig5/plot_fig5_joint_probability.py
python figures/supplementary/plot_pade_validation.py
```

Each writes into its own `output/` directory. Set `QRQT_OUTDIR` to send them elsewhere.
Nothing writes into the manuscript tree.

To check a regenerated file against the submitted one, note that
`checksums/published_figures.sha256` lists paths **relative to the manuscript's figure
directory**, not to this repository — this repository does not redistribute the published
PDFs. Run it from the manuscript tree:

```bash
cd /path/to/natcomms_revision && sha256sum -c /path/to/qrqt-code/checksums/published_figures.sha256
```

Then compare a regenerated file against the published one. The PDFs differ in the embedded
`/CreationDate` (6-8 bytes); at 300 dpi the renders are identical for Figs. 3a, 3b and
Supplementary Fig. 1, and differ in 49 antialiased pixels for Supplementary Fig. 2.

Fig. 2 is different. `figures/fig2/build_diagram.cjs` needs Node (verified on v20) and has
no npm dependencies:

```bash
cd figures/fig2 && node build_diagram.cjs
```

That regenerates the intermediate vector drawing. The published PDF was then produced from
it in Adobe Illustrator with the scripts under `figures/fig2/illustrator/`, so the final
step cannot be run headlessly; set the `base` variable at the top of each `.jsx` to your
project root first. The helper `match_figure_palette.cjs` needs `npm install xml-js`.

## Source Data

```bash
python source_data/make_source_data.py
python source_data/make_holevo_source_data.py            # add --verify for the checks
```

The first writes the CSVs for Figs. 3a, 3b and 5 and Supplementary Figs. 1 and 2, plus the
coherence benchmarks and shaded bands of the top panel of Fig. 3b. Figs. 3a, 3b and 5 are
generated by importing the plotting scripts' own constants and functions, so those cannot
drift from the plots. The two supplementary panels and the Fig. 3b benchmark table are
retyped rather than imported, so check them against
`figures/supplementary/plot_pade_validation.py` and `figures/fig3/pqc_plot_fig3b.py` if
either changes.

The second writes the CSVs behind Figs. 6 and 7. Those are the collaborator's plots and
their plotting code is not available; the CSVs are an independent recomputation from the
closed-form expressions the paper states, at the parameters printed on each panel. See
`FIGURE_INDEX.md` for how the agreement was checked, and replace them with the
collaborator's own numbers when those become available.

## Layout

```
figures/fig3/            Fig. 3a and 3b: memory lifetime vs communication distance
figures/fig5/            Fig. 5: joint classical-quantum attack probability
figures/supplementary/   Supplementary Figs. 1 and 2: Pade approximation validation
figures/fig2/            Fig. 2: overview figure (Node + Illustrator)
source_data/             Source Data generators and the generated CSVs
checksums/               SHA-256 of the six published figure files, keyed by their
                         path in the manuscript tree
```
